# Avanti Joshi | Web Developer Portfolio

A responsive personal portfolio website that showcases my skills, education and projects as a Full Stack Developer. It is built with plain HTML, CSS and JavaScript, so it loads fast and needs no build step.

**Live site:** [your-username.github.io/your-repo-name](https://your-username.github.io/your-repo-name)

## Features

- Responsive layout that works on desktop, tablet and mobile
- Slide-in navigation menu on small screens
- Tabbed About section for Skills, Experience and Education
- Main Projects with hover details, and a More Projects section with tech tags
- Downloadable resume
- Smooth scrolling between sections
- Colour theme controlled from one place using CSS variables

## Run Locally

1. Clone the repository
   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   ```
2. Open the folder
   ```bash
   cd your-repo-name
   ```
3. Open `index.html` in your browser, or use the Live Server extension in VS Code.

## Customize

- **Colours:** edit the variables under `:root` at the top of `style.css`.
- **Projects:** copy an existing project card in `index.html` and change the text, tags and links.
- **Resume:** replace `Resume.pdf` with your own file, keeping the same name.

## Deploy on GitHub Pages

1. Push the project to a GitHub repository.
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and the `/ (root)` folder, then save.
4. Your site will be live at `https://your-username.github.io/your-repo-name` within a few minutes.
